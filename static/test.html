About the Widget

This page embeds the Restaurant Agent chat widget. You should see a floating orange button in the bottom-right corner. Click it to open the chat panel and ask about dishes, allergens, or recommendations.

Session ID is persisted in sessionStorage — reloading the page keeps the same session.

Embed Code

Add this single script tag to any restaurant website:

<script
  src="/static/widget.js"
  data-tenant-id="demo"
  data-restaurant-name="Bella Cucina"
  data-theme-color="#e85d26"
></script>

Available attributes:

  • data-tenant-id — your restaurant's tenant ID (required)
  • data-restaurant-name — display name in the widget header
  • data-theme-color — hex colour for the button and header
  • data-api-base — override API base URL (defaults to same origin)
